What is Git?

Git is a version control system. It helps developers keep track of changes made to files over time. This is useful because you can go back and see what was changed, when it was changed, and why.

What is GitHub?

GitHub is a website where people can store and share code projects. I used GitHub to back up my portfolio so I can still access it after this class ends.

How I Uploaded My Site

First, I created a new repository called dw-html-portfolio. Then I uploaded the files and folders from my site folder. After that, I enabled GitHub Pages from the repository settings so my website could be viewed online.

Why This Is Useful

Using GitHub gives me a backup of my work and makes it easier to share my portfolio with others. It also helps organize projects in one place.
